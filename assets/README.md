# Sanctuary Visual Assets

This directory holds local image assets for the Obsidian Aurora Landscape Sanctuary.
In production and GitHub Pages deployment, the application loads high-resolution photography from curated Unsplash Arctic nocturnal imagery and features resilient CSS/SVG gradient fallback containers to guarantee zero broken image frames.
